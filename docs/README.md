# Documentation

Two kinds of docs live here:

1. **The research record** ([`research/`](research/)): a faithful, structured copy of the original
   research conversation, with all 80 sources. Treat it as the project's founding literature review.
   Don't edit it to track current thinking. Record changes in decisions and the log instead.
2. **Operational docs** (this folder): how the project is actually run. Keep these current.

| Doc | What it's for |
|---|---|
| [`roadmap.md`](roadmap.md) | V0–V6, the two branches, gates, the EEG track, and where each experiment fits. **Start here.** |
| [`architecture.md`](architecture.md) | System design: Intent Bus, Haptic Bus, LSL, contracts, voice pipeline |
| [`hardware.md`](hardware.md) | What to buy, when, and why, by stage, with 2026 prices from the research |
| [`research-protocol.md`](research-protocol.md) | How to run experiments well: blinding, held-out data, variance, logging |
| [`metrics.md`](metrics.md) | Definitions of every metric (control, signal, immersion, effort E/R, proficiency S) |
| [`safety.md`](safety.md) | The hard boundaries. Read before building anything that touches a body |
| [`research-log.md`](research-log.md) | Dated lab notebook: every session, result, surprise and failure |
| [`decisions/`](decisions/) | Architecture/research decision records (ADRs) |
