# 0005 — Read-only sensing + physical feedback only

- Status: accepted
- Date: 2026-10-05

## Context
The research draws a clear line: experiment freely with recording and mechanical/audio/airflow feedback,
but do **not** DIY electrical brain stimulation, nerve stimulation or GVS; no restraints, sleep induction
or neurological movement inhibition ([research/03 §10](../research/03-diy-research-strategy.md),
[research/04](../research/04-research-program-guide.md)).

## Decision
[`docs/safety.md`](../safety.md) is binding for every build and experiment in this repo.

## Consequences
Some fictional full-dive elements (vestibular motion, direct neural touch) are explored only through
multisensory illusion, which is the research's bet anyway. Changing this requires a new ADR *before* any build.
